# Protocolo de Mantenimiento Trimestral – ASTTIN

Aplicación web para el protocolo de mantenimiento trimestral de instrumentación sísmica / acelerógrafos.

Sitio: https://jorgesabattin.github.io/protocolo-asttin/

- Un solo archivo (`index.html`), sin dependencias de servidor.
- Los protocolos se guardan en el navegador del dispositivo; use *Exportar respaldo* para traspasarlos.
- Exporta CSV, informe HTML e impresión a PDF.
- Confirmación opcional del técnico con huella (WebAuthn), ligada al contenido del protocolo.
- Instalable en el celular ("Agregar a pantalla principal") con el ícono de ASTTIN.
